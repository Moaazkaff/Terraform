# Lab 3 Terraform Configuration

This directory contains a Terraform configuration for deploying a small AWS networking setup with a public EC2 instance. The lab creates a VPC, public subnet, internet gateway, route table, security group, and one EC2 instance that can be used as a bastion host.

## Contents

| File | Description |
| --- | --- |
| `provider.tf` | Configures the AWS provider and required provider version. |
| `variables.tf` | Defines input variables used by the Terraform configuration. |
| `terraform.tfvars` | Provides local values for the variables, such as AWS region, CIDR blocks, instance type, SSH key pair, and allowed SSH source IP. |
| `network.tf` | Creates the VPC, internet gateway, public subnet, route table, route table association, and default internet route. |
| `security.tf` | Creates the security group and its SSH ingress and outbound egress rules. |
| `ec2.tf` | Creates the EC2 instance in the public subnet. |
| `outputs.tf` | Prints useful resource IDs and the EC2 public IP after apply. |
| `.terraform/` | Local Terraform working directory created by `terraform init`. |
| `.terraform.lock.hcl` | Provider dependency lock file generated by Terraform. |

## Resources Created

- AWS VPC named `lab3_vpc`
- Internet gateway named `lab3-igw`
- Public subnet named `public-sb`
- Public route table named `public-rt`
- Route to `0.0.0.0/0` through the internet gateway
- Security group named `public-sg`
- SSH ingress rule for the configured allowed IP
- Open outbound egress rule
- EC2 instance named `lab3`

## Input Variables

| Variable | Purpose |
| --- | --- |
| `aws_region` | AWS region where resources are deployed. |
| `vpc_cidr` | CIDR block assigned to the VPC. |
| `public_subnet_cidr` | CIDR block assigned to the public subnet. |
| `availability_zone` | Availability Zone for the public subnet. |
| `instance_type` | EC2 instance type for the bastion host. |
| `key_pair_name` | Existing AWS key pair attached to the EC2 instance. |
| `allowed_ssh_ip` | Source IP range allowed to connect to the instance over SSH. |

## Outputs

| Output | Description |
| --- | --- |
| `vpc_id` | ID of the created VPC. |
| `public_subnet_id` | ID of the public subnet. |
| `public_security_group_id` | ID of the public security group. |
| `public_instance_id` | ID of the EC2 instance. |
| `lab3_public_ip` | Public IP address of the EC2 instance. |

## Usage

Initialize Terraform:

```bash
terraform init
```

Review the planned changes:

```bash
terraform plan
```

Apply the configuration:

```bash
terraform apply
```

Destroy the created resources when finished:

```bash
terraform destroy
```

## Notes

- `terraform.tfvars` contains environment-specific values. Review it before running `terraform apply`.
- `key_pair_name` must match an existing AWS EC2 key pair in the selected region.
- `allowed_ssh_ip` should use CIDR notation, for example `203.0.113.10/32` for a single IP address.
- `public_subnet_cidr` must be a valid subnet CIDR inside the configured VPC CIDR range.
- The AMI ID in `ec2.tf` is hardcoded, so confirm it exists in the configured AWS region before applying.
